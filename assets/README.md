# Frontend assets

`ClimateGuard_Frontend_Lab.html` at the repository root is the main frontend.
`frontend-lab.css` defines the operations layout and light/dark appearance;
`frontend-lab.js` connects its presentation controls to the data adapters and maps
in the HTML. These filenames are retained from the initial design work.

`third-party/flag-icons-LICENSE.txt` credits the Canadian maple leaf geometry.
Additional media, screenshots and recordings can also live in this folder.

`ClimateGuard_Mockup.html` preserves the previous layout.
