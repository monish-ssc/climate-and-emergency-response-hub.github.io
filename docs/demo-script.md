# Two-minute demo script

1. Open ClimateGuard AI and explain that all visible values are simulated.
2. Select Vancouver and show the wildfire risk overview.
3. Switch to Halifax and select the severe-storm scenario.
4. Explain the score using the temperature and wind indicators.
5. Generate the preparedness briefing.
6. Close with the production path: live data, validated risk rules, grounded AI output, and human approval.

## Backup plan

The core demo runs without network access. If a live API fails, use the bundled scenarios and state clearly that the application has entered demonstration mode.
